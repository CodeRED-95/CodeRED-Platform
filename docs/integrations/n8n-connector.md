# Conector oficial n8n CodeRED

Paquete: `@n8n-nodes-codered/codered`. Incluye credencial `CodeREDApi` y nodo `CodeRED`. El secreto se almacena exclusivamente en credenciales cifradas de n8n. No use variables de entorno, Data Tables, static data ni nodos Code para secretos.

Operaciones: Pair Instance, Test Connection, Register Discovery, Send Heartbeat, Create Token Request, Get Token Request Status, Retrieve Approved Token, Confirm Token Delivery, Cancel Token Request y Send Custom Service Event.
