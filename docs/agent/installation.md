# Instalación CodeRED Agent

Variables: CODERED_AGENT_NAME, CODERED_PLATFORM_URL, CODERED_AGENT_PUBLIC_URL, CODERED_AGENT_ENVIRONMENT, CODERED_AGENT_PORT, CODERED_AGENT_DATA_PATH, CODERED_AGENT_ENCRYPTION_KEY, CODERED_AGENT_LOCAL_API_TOKEN.

Comandos:

```bash
docker compose build codered-agent
docker compose up -d codered-agent
docker compose logs -f codered-agent
```
